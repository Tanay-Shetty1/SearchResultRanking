
# Search Result Ranking Demonstrator

A mini-project demonstrating information retrieval and search result ranking using Python, Flask, TF-IDF, and cosine similarity.

## Features
- Search documents using text queries
- Rank results by relevance score
- Flask web interface
- Automated tests using pytest
- Docker container deployment
- Jenkins CI/CD pipeline

## Run locally
```bash
pip install -r requirements.txt
python app.py
```

Open http://localhost:5000 in your browser.

## Testing
```bash
pytest -v
```
